# 🗄️ The Prompt Vault: Developer Edition

Ever feel like your AI assistant suddenly got dumb? It's probably not the model's fault—it's the prompt. The Prompt Vault is a plug-and-play solution for engineers who want to work 3x faster without compromising code quality.

The main goal of this repository is to document battle-tested *system prompts* and *personas* frequently used in Software Development (especially for PHP, TypeScript, SQL, and MongoDB). Just copy-paste, adjust the context, and let the AI do the heavy lifting as your pair programmer.

## 🚀 Quick Start

1. **Pick a Category:** Find the prompt you need in the vault (Architecture, Code Review, etc).
2. **Copy & Customize:** Copy the prompt, then replace the placeholder variables (usually enclosed in brackets like `[INSERT CODE HERE]` or `[PROJECT CONTEXT]`) with your actual code or requirements.
3. **Paste to your LLM:** Send it to your favorite AI (Claude, ChatGPT, or Gemini) and enjoy the results!

💡 **Sneak Peek: Regular vs Vault**
> ❌ **Regular Prompt:** "Please review this PHP code."
> ✅ **Vault Prompt:** "Act as a Principal Backend Engineer. Review the following PHP code, focusing on memory efficiency, potential SQL injection vulnerabilities, and provide refactored code using PSR-12 standards..."

## 🧐 The Why: Prompting is Engineering

In a long context window, **the prompt is the foundation**. If your prompt is weak, the code or review generated by the AI will be vague. A great prompt needs clear **Constraints**:

*   **📏 Length:** "Explain in 3 short paragraphs."
*   **📐 Format:** "Present the review as bullet points and provide the refactored code."
*   **🎭 Style:** "Use a firm, authoritative tone like a Principal Engineer."
*   **📦 Content:** "Focus solely on database query optimization, ignore UI/UX."

*Pro Tip: A single specific constraint can turn a mediocre AI output into an exceptional one.*

## 🧠 AI Model Characteristics

One prompt doesn't always fit all. Here's a quick guide to help you tweak the prompting style from this repo according to the LLM you're using:

| AI Model | Characteristics & Preferences | Prompting Tricks |
| :--- | :--- | :--- |
| **Claude (Anthropic)** | Natural, highly detailed, and great at reading large files/logs. | Use XML tags like `<code_block>` or `<context>` to separate instructions from data. |
| **ChatGPT (OpenAI)** | Super logical and strictly follows formatting rules. | Guide it slowly with *"Let's think step-by-step"* and provide examples of the desired output. |
| **Gemini (Google)** | Fast, efficient, great at extracting facts and quick research. | Give *to-the-point* instructions, clear boundaries (what it *should not* do), and neat visual formatting. |
