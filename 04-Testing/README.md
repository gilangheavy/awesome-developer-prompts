# 🧪 04 - Testing & QA

**Purpose:**
The prompts in this folder are used to generate all types of automated tests (Unit Tests, Integration Tests, to E2E Tests). The AI will be instructed to write tests that focus on application behavior, ensuring the happy path and various edge cases are fully covered.

**When do you need these prompts?**
- If your team practices Test-Driven Development (TDD) and you need to quickly generate boilerplate tests.
- When you need a robust test suite for a newly developed feature (using frameworks like Jest, Pest, PHPUnit, Vitest, or Cypress).
- When you're struggling to mock third-party services (like Stripe or AWS S3) in your tests.
