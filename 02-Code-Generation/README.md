# 💻 02 - Code Generation

**Purpose:**
A collection of *Software Engineer* personas to generate structured, scalable, and secure actual code. The prompts here are designed with *Clean Code*, *SOLID* principles, and *Test-Driven Development (TDD)* in mind.

**Directory Structure:**
- `Backend/` - Backend-specific personas (PHP, Node.js/NestJS, Python, Golang, etc.)
- `Frontend/` - Frontend-specific personas (React, Vue, Svelte, etc.)
- `FullStack/` - Personas for meta-frameworks (Next.js, Nuxt, Laravel Livewire, etc.)

**How to Use:**
Simply pick the persona file that matches your stack, copy its contents, and set it as the *System Prompt* in your IDE (like Cursor/Windsurf) or in the Claude/ChatGPT Web UI. Start writing code with the AI like a pair of veteran programmers!
