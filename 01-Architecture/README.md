# 🏛️ 01 - Architecture & System Design

**Purpose:**
The prompts in this folder are dedicated to the foundational design phase of your application. From High-Level Design (HLD), tech stack selection, database schema design (ERD), to API contract planning (REST/GraphQL).

**When do you need these prompts?**
- When you're starting a project from scratch and need a solid blueprint.
- When you need a brainstorming partner (AI) to weigh the trade-offs between a Monolith and Microservices architecture.
- When you want the AI to design an efficient database schema, complete with indexes and relationships.
