# 🕵️‍♂️ 03 - Code Review

**Purpose:**
The prompts in this folder turn the AI into a strict and meticulous *Principal Engineer* or *Security Auditor*. The main focus is to hunt down security vulnerabilities, memory inefficiencies, performance bottlenecks (e.g., N+1 queries), and clean code violations.

**When do you need these prompts?**
- Right before you create a Pull Request (PR) or push code to production.
- When you need a second opinion (as an auditor) to ensure there are no SQL injection or XSS vulnerabilities.
- When you want the AI to refactor your code snippets to be cleaner and more maintainable.
